For your IT team: how to verify this in a few minutes
  1. Save this page, disconnect from the network, open the saved copy and run it. It works the same.
  2. Open the browser's developer tools, go to the Network panel and run it. The list stays empty.
  3. Read the page's first lines. Its Content Security Policy (default-src 'none'; connect-src 'none') tells the browser to block every fetch, upload and outside file the page could ask for. The policy doesn't govern the page sending the tab elsewhere, so the page has no links and no code that opens another site.
  4. Read the source. It's one file with nothing loaded from anywhere, and the code is public with an automated test that fails the build on any network request.

    What it does
    

    A cleaner P&L, and a short list for the owner
    

      

    • Every account lands in a standard cost category (support staff, building, supplies, billing, insurance and the rest), so the practice can be set beside others. Provider pay, interest, depreciation and taxes are kept apart.
      • 

    • Charges that look personal are grouped by payee and sorted by how likely they are to be owner spending: High is counted as an add-back now, Medium waits for the owner's answer, and Low is a store worth sampling.
      • 

    • The owner answers once. Write personal, business or a percent next to each line of the review list, add that file next time, and the totals update.
      • 

    • It checks its own math. The account lines are added back up and compared with the report's own totals, and the record says if they differ.
      • 

    • Patient details stay out. Refunds to patients and income lines are rolled up with no names, memos are never written out, and names of individuals become codes.
      • 

    

    No AI runs here, only plain rules anyone can read in this page's code. The benchmarks are the best public figures and are dated; the record says where each comes from.
