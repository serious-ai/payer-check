Your files never leave this computer

Everything runs in this browser tab. The page has no code that talks to the internet and no links to other sites, and its security policy tells the browser to block every fetch, upload and outside file the page could ask for.

How your IT person can check: save this page, turn off Wi-Fi, open the saved copy and run it. It works the same. They can also watch the browser's Network panel during a run (it stays empty) or read the source, which is one file with nothing loaded from anywhere.

Each anesthesia line is priced as (base units + time units + any physical status units) times the payer's conversion factor, times the share its modifier pays. A gap is split into the reason that explains it, in the order of the columns from right to left.

Cost per $100 paid adds the dollars paid short (lower codes and short pays, anesthesia included, priced at your contract), denied dollars never recovered, and staff time, then sets it against what the payer paid.

Save the results

The summaries hold totals only, with no patient-level fields. The chart-pull list (and the anesthesia pull list) has a row for every flagged line with its patient account number, so keep it on this computer.

What it reads

From each 835: the payer, each claim's account number, status and received date, the rendering provider, and each service line's codes, modifiers, units, dates, amounts and adjustment codes. It never reads the patient's name. No AI model runs here, only plain code you can read in this file.
